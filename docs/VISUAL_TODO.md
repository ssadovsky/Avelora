## Что уже есть в коде (НЕ переделывать с нуля)
- `terrain.js`: splat-шейдер (трава/тропа/пляж/скала по высоте, уклону и сегментам путей), normalMap.
- `environment.js`: чанковый `buildInstanced` (~20 м, frustum culling), ветер `addWindSway`, крест-квады травы, кусты, папоротники, одуванчики, камыш.
- `main.js`: ACESFilmic, FogExp2, купол неба (шейдер), PCFSoft тени 2048 вокруг героя, DPR ≤ 2.
- UI на DOM/CSS поверх canvas (`ui_hotbar.js`, стили в HTML), классы `touch-ui`.

## Диагноз (почему «так себе»)
1. Земля — один повторяющийся тайл травы, нет макро-вариаций цвета → «зелёный ковёр».
2. Мало мелких деталей: нет цветов, камней, веток, пятен земли, подлеска → глазу не за что зацепиться.
3. Деревья редкие, «кружевные», без массы листвы; нет групп/опушек/кластеров.
4. Свет плоский: слабая разница свет/тень, нет цветового разделения (тёплое солнце / холодные тени), нет дымки по глубине.
5. Нет «жизни»: частицы, лучи, свечение посоха, пыльца.
6. UI: тёмные плашки с тонкой золотой рамкой, пустые чёрные круги, нет единого стиля (камень/металл/пергамент).
7. Герой маленький на фоне пустоты, нет вторичного фокуса (аура, тень-блоб, свечение).

## Что НЕ делаем / ограничения
- Фотореализм «как на арте» (миллионы полигонов травы, объёмный свет, SSAO, реальный GI) — нет. Берём стилизацию.
- Никаких серверов, внешних CDN в рантайме, динамической подгрузки по сети.
- Не включать динамические тени на всё подряд и не возвращать PMREM/IBL (см. GEMINI.md §7).
- Постобработка (bloom/SSAO) — только high-профиль и только после V0, как опция.
