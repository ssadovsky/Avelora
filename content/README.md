# content/ — предметы, объекты, навыки

Здесь лежат **данные** игровых сущностей: у каждой своя папка с JSON-описанием,
3D-моделью и иконкой. Движок (items.js, world_objects.js, skills.js, ui_hotbar.js)
ничего не знает о конкретных предметах — всё берётся отсюда.

Игра запускается с `file://` и не может читать JSON напрямую, поэтому после
**любой** правки в `content/` нужно пересобрать данные:

```
python temp_work/build_assets.py
```

Скрипт собирает все JSON и иконки в `content_data.js` (`window.GAME_CONTENT`),
а модели — в `assets_data.js` (`window.GAME_ASSETS.models['<категория>/<id>']`).

## Структура

```
content/
  items/<id>/        предметы (в сумку, на панель действий, в руку)
    item.json        описание (обязательно)
    model.glb        3D-модель (необязательно)
    icon.png         иконка для сумки/панели (необязательно)
    preview.png      картинка для людей — сборка её игнорирует
  props/<id>/        статичные объекты мира (пень ...)
    prop.json, model.glb, preview.png
  skills/<id>/       навыки
    skill.json, icon.png
  characters/<id>/   какие навыки есть у персонажа (id из characters.js)
    skills.json
```

- Имя папки = `id`. Поле `"id"` в JSON должно совпадать с именем папки
  (иначе сборка остановится с ошибкой).
- Нет `model.glb` — в игре будет простая нейтральная заглушка (брусок/цилиндр).
- Нет `icon.png` — рисуется плитка с первой буквой названия.
- Нет `characters/<id>/skills.json` — у персонажа нет навыков, кнопка
  «Навыки» для него скрыта.

### Правила для моделей

- glTF, ось **+Y вверх**, единицы — **метры** (реальный размер).
- Верхние узлы сцены — варианты `variant_0`, `variant_1`, ... (в кучке на земле
  чередуются разные варианты; вариант может состоять из нескольких мешей).
- Предметы на земле и props: начало координат варианта — **центр низа**
  (y = 0 — самая нижняя точка), брёвна лежат вдоль оси X.
- Предметы «в руку» (топор, посох): начало координат — **точка хвата**,
  рукоять вдоль **+Y**, лезвие топора смотрит в **+X**.

## item.json

```json
{
  "id": "stone",
  "name": "Камень",
  "description": "Увесистый булыжник. Пригодится для строительства и ремесла.",
  "category": "material",
  "stackMax": 20,
  "ground": { "variants": 5, "scale": 1.25, "pile": "heap" },
  "use": null
}
```

| Поле | Значение |
|---|---|
| `id` | уникальный id = имя папки |
| `name` | название (подсказки, «+5 Камень») |
| `description` | описание в подсказке |
| `category` | `material` / `tool` / ... (сейчас только для описания) |
| `stackMax` | сколько штук помещается в одну ячейку сумки (1 = не складывается) |
| `ground.variants` | сколько вариантов в model.glb (для справки) |
| `ground.scale` | масштаб модели, лежащей на земле (1.0 = реальный размер; камни чуть увеличены, чтобы их было видно сверху) |
| `ground.pile` | как выглядит кучка: `heap` (горка), `stack` (поленница), `single` (один предмет) |
| `use` | действие предмета или `null`. `{ "type": "equip", "hand": "right" }` — взять в правую руку / убрать |
| `hold` | необязательно, только для предметов «в руку»: `{ "rotation": [x, y, z], "position": [x, y, z] }` — доповорот (радианы) и сдвиг (м) поверх хвата персонажа. Базовый хват держит инструмент как топор (рукоять вперёд-вниз); посоху задан `hold.rotation`, чтобы он стоял вертикально навершием вверх |

**Панель действий (1…0)** принимает только то, что можно *сделать*: навыки и
предметы с `use` ≠ `null`. Материалы (`use: null`) на панель не кладутся —
ячейка мигает красным: «Нельзя: у предмета нет действия».

## prop.json

```json
{ "id": "stump", "name": "Пень", "obstacle": 0.45 }
```

| Поле | Значение |
|---|---|
| `name` | название |
| `obstacle` | радиус (м), который нельзя пройти; об него же разбиваются снаряды. `0` — проходимый |

Расставляются в `world_data.js` → `props` (см. world_data_help.txt, раздел 10).

## skill.json

```json
{
  "id": "spark",
  "name": "Искра",
  "description": "Сгусток магии летит к указанной точке и разлетается снопом искр.",
  "type": "projectile",
  "cooldown": 0.8,
  "range": 18,
  "speed": 22,
  "castTime": 0.2,
  "damage": { "min": 4, "max": 8, "type": "lightning" },
  "vfx": {
    "color": "#7fd4ff", "core": "#ffffff", "size": 0.55,
    "trail": 14, "impactSparks": 28, "impactRadius": 1.4
  }
}
```

| Поле | Значение |
|---|---|
| `type` | тип навыка; поведение пишется в движке один раз на тип. Сейчас есть `projectile` |
| `cooldown` | перезарядка, секунды игрового времени (на паузе не идёт) |
| `range` | дальность, м |
| `speed` | скорость снаряда, м/с |
| `castTime` | время замаха: персонаж останавливается и поворачивается к цели, затем снаряд вылетает из правой руки |
| `damage` | урон `{min, max, type}` — пока не используется (нет врагов), но передаётся в событие попадания `game:skillImpact` |
| `vfx.color` | цвет свечения, следа, искр и кольца |
| `vfx.core` | цвет яркого ядра и вспышки |
| `vfx.size` | размер ядра, м |
| `vfx.trail` | длина следа (число точек) |
| `vfx.impactSparks` | сколько искр при попадании |
| `vfx.impactRadius` | радиус кольца на земле при попадании, м |

**Прицел `projectile`:** точка на земле под курсором мыши (не дальше `range`);
после касания пальцем или если под курсором нет земли — прямо вперёд на всю
дальность. Снаряд разбивается о землю, деревья, валуны, кусты и props.

## characters/<id>/skills.json

```json
{ "character": "mage", "skills": ["spark"] }
```

`<id>` — id персонажа из `characters.js` (`warrior`, `archer`, `mage`).
Сборка проверяет, что каждый навык из списка существует.

## item.json → `weapon` (оружие ближнего боя)
`"weapon": { "damage": [6, 10], "range": 1.7, "cooldown": 1.1, "chop": 1 }` — урон (мин–макс),
дальность удара (м), пауза между ударами (с), `chop` — может рубить деревья. Без поля `weapon`
предмет в руке не даёт урона: персонаж бьёт кулаками (1–3).

## creatures/<id>/creature.json (существа)
| поле | смысл |
|---|---|
| `hp`, `damage` [мин, макс] | здоровье и урон одного укуса/удара |
| `attackRange`, `attackCooldown` | с какого расстояния бьёт (м) и как часто (с) |
| `walkSpeed`, `runSpeed` | скорость, когда бродит / гонится (м/с) |
| `behavior` | `retaliate` — мирное, пока не ударишь; `aggressive` — нападает само |
| `aggroRadius` | с какого расстояния замечает игрока (для `aggressive`) |
| `leashRadius` | дальше этого от «дома» — бросает погоню и возвращается |
| `wanderRadius` | как далеко бродит от «дома» |
| `respawnMinutes` | через сколько минут сыгранного времени возрождается |
| `hitRadius`, `scale` | размер для кликов/попаданий, масштаб модели |

Модель `model.glb`: смотрит в +Z, ноги на y=0, анимации `Idle`, `Walk`, `Run`, `Attack`, `Hit`, `Death`
(делается генератором, см. `temp_work/procgen/README.md`). Ставится в мир массивом `creatures`
в `world_data.js`: `{ id, type, x, z, r? }`.

## nodes/<id>/node.json (ресурсы, которые добывают)
Сейчас одно: `tree` — деревья. `kind` (какие объекты окружения), `tool` (`chop` — нужно оружие
с `chop`), `hits` (сколько ударов), `drops` [`{item, min, max}`] (что выпадет на землю),
`regrowMinutes` (через сколько минут игры отрастёт), `stump` (какой props остаётся).

## Как добавить новый предмет

1. Создайте папку `content/items/<id>/` (латиница, например `rope`).
2. Напишите `item.json` по образцу выше (`id` = имя папки).
3. Положите `model.glb` и `icon.png` (можно позже — будут заглушки).
4. Запустите `python temp_work/build_assets.py`.
5. Чтобы предмет лежал в мире, добавьте кучку в `world_data.js` → `pickups`
   нужной локации: `{ id: 'rope_1', item: 'rope', count: 2, x: 5, z: 7 }`.

## Как добавить новый навык

1. Создайте папку `content/skills/<id>/` и `skill.json` с существующим `type`
   (`projectile`) и своими параметрами/цветами. Новый *тип* поведения требует
   кода в `skills.js` (метод `activate()` ветвится по `type`).
2. По желанию положите `icon.png`.
3. Выдайте навык персонажу (ниже) и запустите `python temp_work/build_assets.py`.

## Как выдать навык персонажу

1. Откройте (или создайте) `content/characters/<id персонажа>/skills.json`.
2. Допишите id навыка в список `skills`.
3. Запустите `python temp_work/build_assets.py`.

У персонажа появится кнопка «Навыки» (книга слева от сумки, клавиша **K**);
навык перетаскивается из окна на панель действий и запускается клавишей 1…0
или нажатием на ячейку.

## Как добавить новый статичный объект (props)

1. Папка `content/props/<id>/` с `prop.json` (`name`, `obstacle`) и `model.glb`.
2. `python temp_work/build_assets.py`.
3. Поставьте его в `world_data.js` → `props`:
   `{ id: 'my_stump', prop: '<id>', x: 3, z: 4, r: 0.5, s: 1.0 }`.
