========================================================================
ИНСТРУКЦИЯ ПО НАСТРОЙКЕ МИРА И ЛОКАЦИЙ (world_data.js)
========================================================================

Игра теперь состоит из НЕСКОЛЬКИХ локаций (карт), между которыми можно
переходить прямо во время игры — прошёл через светящийся круг ("проход")
на краю карты, и через мгновение ты на соседней локации. Всё это
настраивается здесь, в world_data.js, без правки движка.

Структура одной локации:

window.LOCATIONS = {
    lakeLand: {
        id: 'lakeLand',
        name: 'Озерный край',   // видно на экране загрузки и при входе
        terrain: { ... },        // размер, рельеф, водоём
        atmosphere: { ... },     // цвет неба, туман (необязательно)
        spawns: { ... },         // точки появления персонажа
        exits: [ ... ],          // проходы на другие локации
        clearings: [ ... ],      // места, где группы объектов НЕ ставят деревья/траву
        groups: [ ... ],         // ГРУППЫ объектов (лес, камыш, камни, луг)
        decorations: { ... },    // объекты, расставленные вручную по одному
        pickups: [ ... ],        // кучки предметов, которые можно подобрать (раздел 9)
        props: [ ... ]           // статичные объекты из content/props: пень и т.п. (раздел 10)
    },
    forestEdge: { ... }
};

Быстрая проверка одной локации без похода через весь мир:
откройте index.html#forestEdge (после # — id локации).


------------------------------------------------------------------------
1. РЕЛЬЕФ И РАЗМЕР КАРТЫ (terrain)
------------------------------------------------------------------------
terrain: {
    size: 120,          // игровая область: квадрат size x size метров
    seed: 4242,          // "зерно" рельефа — поменяйте число, получите другие холмы
    baseHeight: 0.85,    // средняя высота суши над водой (по умолчанию 0.85).
                          // Меньше = больше низин и случайных луж; для маленьких
                          // прудов ставьте 1.5-2.0, чтобы вокруг не было лишней воды.
    waterBody: { ... },   // см. раздел 2
    hills: {
        amplitude: 1.4,   // высота холмов
        inclineX: 0.8,    // общий уклон карты по X (0 = ровно)
        inclineZ: 0.4     // общий уклон карты по Z
    }
}

Видимая земля продолжается на 28 м за пределы size (это поле `border` в
terrain, по умолчанию 28) — так игрок никогда не увидит край мира. Играть
там всё равно нельзя: проходы (exits) и точки появления (spawns) должны
быть внутри size, а не в этой кайме.


------------------------------------------------------------------------
2. ПАРАМЕТРЫ ВОДОЕМА (terrain.waterBody)
------------------------------------------------------------------------
Поддерживается 4 режима водоема:

ВАРИАНТ А: Морское побережье (море вдоль одного из краев карты)
waterBody: {
    type: 'coast',
    side: 'west',        // 'west' (слева), 'east' (справа), 'north' (сверху), 'south' (снизу)
    shoreLine: -10.0,    // Координата линии прибоя (где начинается пляж)
    depth: -2.2,         // Глубина моря
    beachWidth: 14.0     // Ширина пологого песчаного пляжа
}

ВАРИАНТ Б: Замкнутое озеро или маленький пруд
waterBody: {
    type: 'lake',
    x: -14.0,            // Центр озера по оси X
    z: 2.0,               // Центр озера по оси Z
    radius: 24.0,         // Радиус озера в метрах (для пруда — 6-10)
    depth: -1.6,          // Глубина дна озера
    beachWidth: 14.0      // Ширина пляжа (необязательно; для пруда — 4-6)
}
Маленькие пруды (radius < 24) автоматически получают более ровный берег
и быстрее уходят на глубину — форма не будет "рваной", как у большого озера.

ВАРИАНТ В: Остров (суша в центре, а вокруг бескрайний океан)
waterBody: {
    type: 'island',
    radius: 35.0,
    depth: -2.5,
    beachWidth: 12.0
}

ВАРИАНТ Г: Суша без воды (чистый лес или поле)
waterBody: {
    type: 'none'
}


------------------------------------------------------------------------
3. ТОЧКИ ПОЯВЛЕНИЯ (spawns)
------------------------------------------------------------------------
spawns: {
    default:    { x: 15.0, z: 8.0 },                  // обычный старт игры
    fromForest: { x: 45.0, z: 6.0, r: 1.57 }          // куда попадает игрок,
                                                        // придя ИЗ другой локации
}
- x, z — координаты появления.
- r — необязательно, куда смотрит персонаж (в радианах). Без r персонаж
  просто сохраняет тот угол, что был.
- Имя точки (default, fromForest, ...) придумываете сами — на него ссылается
  exits[].spawn на СОСЕДНЕЙ локации (см. ниже).


------------------------------------------------------------------------
4. ПРОХОДЫ МЕЖДУ ЛОКАЦИЯМИ (exits)
------------------------------------------------------------------------
exits: [
    { id: 'toForest', x: 54.0, z: 6.0, radius: 3.0, to: 'forestEdge', spawn: 'fromLake', label: 'Лесная опушка' }
]

- x, z, radius — где на карте находится проход (светящийся круг на земле).
- to — id локации, куда ведёт проход.
- spawn — имя точки в spawns ТОЙ локации, куда попадёт игрок (см. раздел 3).
  Если не указать — попадёт в её spawns.default.
- label — подпись над проходом ("➜ Название"). Без label используется name
  локации to.

СОВЕТ: сделайте проход в паре на обеих локациях (проход A → B рядом с точкой
"fromA" на B, и проход B → A рядом с точкой "fromB" на A), чтобы переход
туда-обратно выглядел естественно — игрок не перепрыгивает через полкарты.

Проход срабатывает, когда игрок ВОШЁЛ в круг после того, как был снаружи —
случайно пройти сквозь него сразу при появлении нельзя.


------------------------------------------------------------------------
5. ГРУППЫ ОБЪЕКТОВ (groups) — ГЛАВНЫЙ ИНСТРУМЕНТ ДЛЯ БЫСТРОЙ РАССТАНОВКИ
------------------------------------------------------------------------
Раньше карту засаживали вручную, объект за объектом — камыш вокруг озера
получался неестественным ровным кольцом. Теперь есть ГОТОВЫЕ ГРУППЫ:
одна строка — и на карте появляется лес, заросли камыша, каменистый
участок или луг, каждый объект внутри — свой, отдельный, со своим id
(в будущем к нему можно будет применить действие: срубить дерево, собрать
камыш и т.д.).

groups: [
    { type: 'forest', x: 30, z: -40, radius: 14, count: 16, seed: 3 },
    { type: 'reeds',  x: -20, z: 5,  radius: 8,  count: 60, seed: 11 }
]

ОБЩИЕ ПОЛЯ (у всех типов групп):
- type      — 'forest' | 'reeds' | 'rocks' | 'meadow' (см. ниже)
- x, z      — центр группы
- radius    — радиус круглой области (метры)
  ИЛИ rx, rz (+ angle) — радиусы эллипса по X и Z и его поворот, если нужна
  вытянутая полоса (например, лес вдоль края карты)
- count     — сколько ГЛАВНЫХ объектов группы (деревьев/камышовых кустиков/
              камней/пятен травы)
- seed      — число; при том же seed раскладка ВСЕГДА одинаковая. Меняете
              seed — получаете другую случайную раскладку той же группы.
              Если не указать seed, он вычисляется из id локации и id
              группы (тоже стабильно, но менее предсказуемо на глаз).
- id        — необязательное имя группы (иначе будет "forest1", "forest2"...).
              Объекты внутри получат id вида "id.tree1", "id.tree2".

ТИПЫ ГРУПП:

  forest (лес/роща)
    Деревья + подлесок (папоротники и трава у стволов).
    { type: 'forest', x, z, radius, count,
      spacing: 3.4,        // минимальное расстояние между стволами (м)
      scaleMin: 0.85, scaleMax: 1.35,
      undergrowth: true,   // false — только стволы, без подлеска
      ferns: 0.7,          // папоротников на 1 дерево (в среднем)
      grass: 1.6,          // пучков травы на 1 дерево
      shrubs: 3 }           // + N кустов в той же области (необязательно)

  reeds (заросли камыша)
    Камыш растёт КУРТИНАМИ (пятнами), а не ровным кольцом, и только на
    мелководье / мокром берегу — на сухой земле его не поставит.
    { type: 'reeds', x, z, radius, count,
      spacing: 0.38,       // теснота внутри куртины
      clumps: 4,           // сколько отдельных куртин (по умолчанию ~count/14)
      clumpRadius: 1.8,    // размер одной куртины
      scaleMin: 0.7, scaleMax: 1.25 }

  rocks (каменистый участок)
    Валуны + трава и папоротники вокруг них.
    { type: 'rocks', x, z, radius, count,
      spacing: 2.6, scaleMin: 0.7, scaleMax: 1.7,
      surface: 'land' }    // можно 'any', если камни должны выходить к воде

  meadow (луг)
    Пятна травы + немного одуванчиков, тоже не идеально ровным ковром.
    { type: 'meadow', x, z, radius, count,
      spacing: 0.55, clumpRadius: 2.6,
      flowers: 10 }        // сколько одуванчиков (по умолчанию ~20% от count)

Группы САМИ обходят проходы (exits), точки появления (spawns) и поляны
(clearings, см. ниже) — деревья и камни там не встанут, дорога останется
чистой.


------------------------------------------------------------------------
6. ПОЛЯНЫ / РАСЧИЩЕННЫЕ МЕСТА (clearings)
------------------------------------------------------------------------
clearings: [
    { x: -48.0, z: 8.0, radius: 6.0 }
]
Круглая область, где группы (groups) ничего не ставят — например, тропа
от прохода вглубь карты, чтобы дорогу к выходу не перегородило лесом.
На decorations (объекты, расставленные вручную) clearings не влияют —
если вы сами поставили дерево в этом месте, оно останется.


------------------------------------------------------------------------
7. ОБЪЕКТЫ ВРУЧНУЮ (decorations)
------------------------------------------------------------------------
Как и раньше — для единичных, особенных объектов (то самое приметное
дерево на поляне, одинокий камень у тропы):

decorations: {
    trees: [ { x: 10.0, z: 5.0, s: 1.2, r: 0.5 } ],
    boulders: [], shrubs: [], ferns: [], dandelions: [], reeds: [], grass: []
}
- x, z — координаты на карте (в метрах)
- s    — масштаб/размер (1.0 = 100%, 0.8 = 80%, 1.5 = 150%)
- r    — угол поворота вокруг вертикальной оси (в радианах, от 0 до 6.28)
- id   — необязательно, свой id объекта (иначе "trees_0", "trees_1", ...)

Координату высоты Y указывать не нужно — движок сам ставит объект на
поверхность земли по рельефу.

Для группы одинаковых объектов без "умной" раскладки по-прежнему можно
использовать createCluster (равномерно-случайный круг, без учёта воды/суши):

grass: [
    ...createCluster(10, 15, 6, 40, 0.9, 1.4, /* seed */ 5),
    { x: 2, z: 4, s: 1.1, r: 0.2 }
]


------------------------------------------------------------------------
8. КАК СОЗДАТЬ НОВУЮ ЛОКАЦИЮ
------------------------------------------------------------------------
1. Скопируйте блок одной из существующих локаций в window.LOCATIONS под
   новым именем (например, mountainPass).
2. Задайте terrain (размер, рельеф, вода), spawns.default, groups и/или
   decorations.
3. Если локация должна соединяться с другими — добавьте exits на этой
   локации и ответный exits+spawn на соседней.
4. Проверьте: index.html#mountainPass

Локация, с которой начинается игра, задаётся в самом верху файла:
window.START_LOCATION = 'forestEdge';


------------------------------------------------------------------------
9. ПРЕДМЕТЫ НА ЗЕМЛЕ, КОТОРЫЕ МОЖНО ПОДОБРАТЬ (pickups)
------------------------------------------------------------------------
pickups: [
    { id: 'start_stones', item: 'stone', count: 5, x: 9.5, z: 14.5 },
    { id: 'start_logs',   item: 'log',   count: 3, x: 2.5, z: 15.5, r: 0.5 },
    { id: 'stump_axe',    item: 'axe',   count: 1, x: 1.35, z: 18.12,
      y: 0.72, rotation: [3.142, 0.347, 1.082] }
]

- id    — ОБЯЗАТЕЛЬНО, уникальное в пределах локации. По нему игра помнит,
          сколько из этой кучки каждый персонаж уже забрал. Если переименовать
          id, кучка снова появится у всех — не меняйте id без причины.
- item  — id предмета из папки content/items (stone, log, axe, staff ...).
- count — сколько предметов в кучке.
- x, z  — где лежит кучка (высота Y — автоматически по рельефу).
- r     — необязательно, поворот всей кучки (радианы). Без r — случайный,
          но всегда одинаковый для этого id.
- y     — необязательно, высота над землёй в метрах (для одиночного
          предмета, например топора, воткнутого в пень).
- rotation — необязательно, [x, y, z] в радианах: точный наклон одиночного
          предмета (count 1). Тогда x, z, y задают точку хвата предмета
          (у инструментов это низ рукояти), а не центр.

Как выглядит кучка: показывается столько моделей, сколько предметов (но не
больше 8), вид раскладки задаётся в item.json предмета полем
ground.pile: 'heap' — горка (камни: часть лежит на земле, часть сверху),
'stack' — поленница (брёвна: два снизу параллельно, одно сверху),
'single' — один предмет. Раскладка случайная, но одинаковая при каждом
запуске.

В игре: наведите мышь — подсказка «Камень ×5»; щёлкните — персонаж сам
подойдёт и подберёт. Если сумка полна, заберёт сколько влезет, остальное
останется лежать. Подобранное запоминается ДЛЯ КАЖДОГО ПЕРСОНАЖА ОТДЕЛЬНО
и не появляется снова после перезагрузки. «Начать заново» возвращает всё
на место.

Группы (groups) не сажают траву и деревья прямо на кучки и объекты props.


------------------------------------------------------------------------
10. СТАТИЧНЫЕ ОБЪЕКТЫ ИЗ content/props (props)
------------------------------------------------------------------------
props: [
    { id: 'start_stump', prop: 'stump', x: 1.0, z: 18.0, r: 0.4, s: 1.0 }
]

- id   — имя объекта (для удобства и будущего взаимодействия).
- prop — id из папки content/props (stump ...).
- x, z — место; r — поворот (радианы); s — масштаб (1.0 = 100%).

Модель берётся из content/props/<prop>/model.glb, а радиус, который нельзя
пройти насквозь, — из поля obstacle в prop.json (умножается на s). Такой
объект персонаж обходит, а снаряды навыков о него разбиваются.

Как добавить новый предмет, навык или объект props — см. content/README.md.



==============================================================
СУЩЕСТВА (creatures)
==============================================================
В локации можно задать массив creatures — кто там живёт:

    creatures: [
        { id: 'pond_rat_1', type: 'rat', x: -3.0, z: -8.0 },
        { id: 'portal_boar', type: 'boar', x: -49.5, z: 9.5, r: 1.57 }
    ]

  id   — уникальное имя в локации (по нему запоминается, кто убит; не переименовывайте зря)
  type — папка в content/creatures (rat, boar, ...)
  x, z — «дом»: там появляется, вокруг бродит, туда возвращается
  r    — начальный поворот (радианы), необязательно

Поведение, здоровье, урон, скорость, радиус агрессии — в content/creatures/<type>/creature.json
(описание полей — content/README.md). Убитые возрождаются через respawnMinutes сыгранного времени.
Не ставьте агрессивных существ ближе ~10 м к точкам появления (spawns).
